# AGENTS.md — Regras gerais do projeto

## 1. Objetivo
Desenvolver um portfólio pessoal moderno, minimalista e sofisticado, com inspiração em sites editoriais e estúdios criativos profissionais.

O site deve apresentar a identidade, habilidades, experiências e projetos do proprietário de maneira visualmente atraente e profissional.

## 2. Tecnologias
- HTML5 para estrutura.
- CSS3 para estilização, responsividade e animações.
- JavaScript puro para interações e funcionalidades.
- Não utilizar frameworks ou bibliotecas desnecessárias.
- Priorizar recursos nativos do navegador.

## 3. Organização do código
- Manter um único arquivo HTML principal.
- Utilizar um único arquivo CSS principal.
- Utilizar um único arquivo JavaScript principal.
- Organizar o HTML em seções identificadas e bem nomeadas.
- Manter o código limpo, organizado e comentado quando necessário.
- Separar imagens, ícones e fontes na pasta assets.

## 4. Documentação obrigatória
Antes de iniciar ou modificar qualquer parte do projeto, ler:
- referencias.md
- identidade.md
- funcionalidades.md
- prompt-principal.md

Respeitar todas as decisões estabelecidas nesses documentos.

## 5. Direção visual
- Seguir uma estética minimalista, editorial e sofisticada.
- Utilizar tipografia de grande escala.
- Priorizar espaços vazios e composições equilibradas.
- Utilizar imagens grandes e layouts assimétricos.
- Manter navegação discreta.
- Evitar excesso de elementos decorativos.
- Não utilizar aparência de template genérico.

## 6. Responsividade
O site deve funcionar corretamente em:
- Computadores.
- Notebooks.
- Tablets.
- Celulares.

Adaptar tamanhos de fontes, imagens, menus, galerias e animações para cada dispositivo.

## 7. Qualidade e acessibilidade
- Utilizar HTML semântico.
- Garantir contraste adequado.
- Adicionar textos alternativos às imagens.
- Permitir navegação por teclado.
- Respeitar a preferência de redução de movimento do usuário.
- Evitar animações que prejudiquem a experiência.
- Otimizar imagens e carregamento.

## 8. Regras de desenvolvimento
- Não inventar informações pessoais, experiências ou projetos.
- Não substituir a identidade visual definida pelo proprietário.
- Não adicionar cores fora da paleta estabelecida sem autorização.
- Não remover funcionalidades solicitadas.
- Não utilizar animações exageradas.
- Não comprometer a velocidade do site por efeitos visuais.
- Testar as funcionalidades após implementá-las.

## 9. Processo de trabalho
Antes de desenvolver, analisar os documentos e planejar a implementação.

Desenvolver por etapas, verificando o resultado de cada uma.

Depois de cada alteração, explicar resumidamente em duas linhas o que foi feito e quais arquivos foram modificados.

Se houver alguma informação pessoal ou conteúdo faltando, utilizar um espaço reservado e solicitar os dados, sem inventá-los.

## 10. Resultado esperado
Entregar um portfólio profissional, visualmente consistente, responsivo, funcional e com personalidade própria, inspirado nas referências fornecidas.
