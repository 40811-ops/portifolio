# Regras do projeto

- Desenvolver um portfólio pessoal usando HTML, CSS e JavaScript puro, sem frameworks.
- Antes de criar ou alterar arquivos, ler `referencias.md`, `identidade.md` e `funcionalidades.md`.
- Organizar o projeto em arquivos separados: `index.html`, `style.css` e `script.js`, além de uma pasta `assets/` para imagens, se necessário.
- Criar obrigatoriamente as seções **Sobre mim**, **Projetos** e **Contato**. Outras seções podem ser adicionadas se fizerem sentido.
- Seguir a identidade visual e as referências descritas nos documentos, sem copiar integralmente sites de terceiros.
- O resultado deve ter identidade própria, evitando aparência de template genérico.
- Não inventar experiências, qualificações, projetos, links ou informações pessoais. Se faltarem informações, usar marcações claramente identificadas para eu preencher ou perguntar antes.
- Garantir funcionamento em celular, tablet e computador.
- Implementar funcionalidades reais; não deixar botões sem ação nem simular envios que não acontecem.
- Respeitar a preferência do sistema por movimento reduzido e manter animações leves.
- Manter código legível, organizado e com nomes descritivos.
- Depois de cada etapa, explicar brevemente o que foi alterado e quais testes foram feitos.
- Antes de considerar o projeto concluído, verificar links, navegação, formulário, alternância de tema, console do navegador, acessibilidade básica e responsividade.
- Se houver instruções contraditórias ou informações essenciais faltando, perguntar antes de tomar decisões importantes.
