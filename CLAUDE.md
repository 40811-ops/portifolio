# CLAUDE.md — Instruções para o Claude

Você será responsável pelo desenvolvimento completo deste portfólio pessoal.

Antes de executar qualquer tarefa, leia obrigatoriamente o AGENTS.md, referencias.md, identidade.md e funcionalidades.md.

## Regras principais

1. Siga rigorosamente as instruções e decisões dos documentos do projeto.
2. Utilize exclusivamente HTML, CSS e JavaScript puro.
3. Preserve a identidade visual minimalista e editorial.
4. Não transforme o projeto em um template genérico.
5. Não invente informações, imagens pessoais ou projetos.
6. Mantenha o código organizado e responsivo.
7. Implemente as funcionalidades na ordem de prioridade definida.
8. Teste as funcionalidades antes de considerar uma etapa concluída.

## Desenvolvimento

Antes de começar uma implementação:
- Analise a estrutura atual do projeto.
- Identifique os arquivos que precisam ser modificados.
- Planeje as alterações.
- Preserve funcionalidades que já estejam funcionando.

Não reescreva arquivos inteiros sem necessidade.

## Design e experiência

O resultado deve transmitir a sensação de um portfólio desenvolvido por um estúdio profissional.

Priorize:
- Tipografia expressiva.
- Espaços negativos.
- Imagens de alta qualidade.
- Movimentos suaves.
- Transições elegantes.
- Interações discretas.
- Consistência entre todas as seções.

## Animações

Todas as animações devem ser leves e fluidas.

Evite:
- Movimentos exagerados.
- Animações constantes sem necessidade.
- Efeitos que prejudiquem a leitura.
- Travamentos durante a rolagem.
- Animações incompatíveis com dispositivos móveis.

## Comunicação

Após cada etapa, apresente um resumo de duas linhas explicando o que foi implementado e quais arquivos foram alterados.

Quando encontrar problemas, corrija-os antes de avançar para a próxima etapa.

Não considere uma funcionalidade concluída apenas porque seu código foi escrito. Verifique seu funcionamento.
