# Identidade visual do portfólio

## 1. Conceito

O portfólio terá uma identidade visual minimalista, editorial e contemporânea.

A proposta é transmitir profissionalismo, criatividade, domínio tecnológico e atenção aos detalhes.

O design deve ser sofisticado sem parecer exagerado, utilizando tipografia expressiva, imagens grandes e bastante espaço negativo.

## 2. Paleta de cores

### Modo claro
- Cor principal: #262626
- Cor de fundo: #F5F5F3
- Cor secundária: #777777
- Cor de bordas: #D8D8D5

### Modo escuro
- Cor principal: #F5F5F3
- Cor de fundo: #171717
- Cor secundária: #A0A0A0
- Cor de bordas: #383838

As cores devem ser utilizadas por meio de variáveis CSS, facilitando a alternância entre os temas.

Não adicionar cores vibrantes ou gradientes sem necessidade.

## 3. Tipografia

### Fonte para títulos
Manrope — utilizar pesos mais fortes para títulos e chamadas principais.

### Fonte para textos
Inter — utilizar para parágrafos, menus, descrições e informações complementares.

A tipografia deve ter hierarquia bem definida, com títulos grandes e textos menores, porém confortáveis para leitura.

## 4. Estilo visual

- Minimalista.
- Editorial.
- Sofisticado.
- Moderno.
- Tecnológico.
- Composição assimétrica.
- Fotografias e imagens em destaque.
- Elementos visuais discretos.

## 5. Elementos de identidade

### Cabeçalho
Menu horizontal discreto, com links para as principais seções e botão de alternância de tema.

### Página inicial
Nome do proprietário em tipografia gigante, seguido de uma breve apresentação e imagem de destaque.

### Galeria
Projetos apresentados por meio de imagens grandes, títulos e descrições curtas.

### Rodapé
Informações de contato, redes sociais e identificação profissional.

## 6. Tom de voz

- Direto.
- Profissional.
- Moderno.
- Criativo.
- Natural.
- Sem textos excessivamente formais.
